# 🍔 CampusSnackPass

CampusSnackPass is a food ordering web application developed using HTML, CSS and JavaScript. It allows users to browse menu items, search, sort, filter by category, add items to the cart, remove items, clear the cart and place an order with a generated token number.

## Features
- Display food items
- Search menu items
- Filter by category
- Sort by price
- Add to Cart
- Remove from Cart
- Clear Cart
- Order confirmation with token number
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
```
CampusSnackPass/
│── index.html
│── style.css
│── script.js
│── images/
```

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Start ordering food.
